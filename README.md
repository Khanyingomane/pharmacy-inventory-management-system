# Pharmacy Inventory Management System (PIMS)

## Project Overview
A Java-based desktop application designed to manage pharmacy inventory, suppliers, users and sales. The system integrates a MySQL relational database to support inventory tracking, transaction processing and reporting.

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- NetBeans

## Key Features
- Secure user login and role-based access
- Medicine inventory management
- Supplier and user management
- Stock monitoring and expiry tracking
- Point-of-sale and billing functionality
- Sales and inventory reporting
- MySQL database integration
- CRUD operations for database records

## Database Management
The application uses MySQL to store and manage:
- User accounts
- Medicine records
- Supplier information
- Sales transactions
- Sales items

JDBC enables communication between the Java application and the relational database.

## Project Objectives
- Demonstrate Java application development.
- Apply relational database design principles.
- Implement SQL-based data management.
- Support accurate inventory and sales records.
- Develop practical database integration and reporting skills.
